Selection Sort

A simple sorting algorithm that repeatedly selects the smallest element from the unsorted portion and moves it to the beginning of the sorted portion.

Time Complexity: O(n²) Space Complexity: O(1) Stable: No
Visualize Algorithm 
function selectionSort(arr) {
  const n = arr.length;
  
  for (let i = 0; i < n - 1; i++) {
    // Find the minimum element in the
    // unsorted part of the array
    let minIndex = i;
    
    for (let j = i + 1; j < n; j++) {
      if (arr[j] < arr[minIndex]) {
        minIndex = j;
      }
    }
    
    // Swap the found minimum element
    // with the first element
    if (minIndex !== i) {
      [arr[i], arr[minIndex]] = 
        [arr[minIndex], arr[i]];
    }
  }
  
  return arr;
}

How Selection Sort Works

Algorithm Description

Selection Sort is a straightforward sorting algorithm that works by repeatedly finding the minimum element from the unsorted portion of the array and putting it at the beginning of the array.

The algorithm maintains two subarrays: the subarray that is already sorted and the remaining subarray that is unsorted. In each iteration, it finds the smallest element from the unsorted subarray and moves it to the end of the sorted subarray.

Key Characteristics

  • Simple Implementation: Easy to understand and implement
  • In-Place: Only requires a constant amount of extra memory space
  • Not Stable: May change the relative order of equal elements
  • Minimal Swaps: Makes the minimum possible number of swaps (at most n-1)

Complexity Analysis

Time Complexity

  • Best Case: O(n²) - Always performs the same number of comparisons
  • Average Case: O(n²) - Requires n² comparisons
  • Worst Case: O(n²) - Always performs the same number of comparisons

Space Complexity

O(1) - Only requires a constant amount of extra memory space for the temporary variables used for swapping and tracking the minimum index.

When to Use Selection Sort

  • When memory write operations are expensive or limited
  • When minimizing the number of swaps is important
  • For small datasets where simplicity is preferred over efficiency
  • As a subcomponent of more complex algorithms

Code Implementation

function selectionSort(arr) {
  const n = arr.length;
  
  // One by one move boundary of unsorted subarray
  for (let i = 0; i < n - 1; i++) {
    // Find the minimum element in unsorted array
    let minIndex = i;
    
    for (let j = i + 1; j < n; j++) {
      // Compare current element with current minimum
      if (arr[j] < arr[minIndex]) {
        minIndex = j;
      }
    }
    
    // Swap the found minimum element with the first element
    // Only if needed (minimum is not already at correct position)
    if (minIndex !== i) {
      [arr[i], arr[minIndex]] = [arr[minIndex], arr[i]];
    }
  }
  
  return arr;
}

    # Traverse through all array elements

        # Find the minimum element in remaining unsorted array
        min_idx = i

            # Compare current element with current minimum

        # Only if needed (minimum is not already at correct position)
        if min_idx != i:

import java.util.Arrays;

public class SelectionSort {
    public static void selectionSort(int[] arr) {
        int n = arr.length;
        
        // One by one move boundary of unsorted subarray
        for (int i = 0; i < n - 1; i++) {
            // Find the minimum element in unsorted array
            int minIndex = i;
            
            for (int j = i + 1; j < n; j++) {
                // Compare current element with current minimum
                if (arr[j] < arr[minIndex]) {
                    minIndex = j;
                }
            }
            
            // Swap the found minimum element with the first element
            // Only if needed (minimum is not already at correct position)
            if (minIndex != i) {
                int temp = arr[i];
                arr[i] = arr[minIndex];
                arr[minIndex] = temp;
            }
        }
    }
    
    public static void main(String[] args) {
        int[] array = {64, 25, 12, 22, 11};
        System.out.println("Original array: " + Arrays.toString(array));
        
        selectionSort(array);
        
        System.out.println("Sorted array: " + Arrays.toString(array));
    }
}

Additional Insights

Performance Considerations

Selection Sort performs poorly on large lists due to its O(n²) time complexity. However, it has some notable advantages in certain scenarios:

  • Minimal Memory Writes: Selection Sort performs at most O(n) swaps, which is minimal compared to other algorithms. This can be beneficial in systems where memory writes are expensive.
  • Predictable Performance: The algorithm always takes the same number of comparisons regardless of input, making its performance predictable.
  • Simple Implementation: The algorithm is straightforward to implement and understand, making it suitable for educational purposes.

Comparison with Other Algorithms

How does Selection Sort compare to other simple sorting algorithms?

  • vs. Bubble Sort: Both have O(n²) time complexity, but Selection Sort typically performs better as it makes fewer swaps (O(n) vs. O(n²)).
  • vs. Insertion Sort: Insertion Sort performs better on partially sorted arrays and has better best-case performance (O(n) vs. O(n²)).
  • vs. Advanced Algorithms: More sophisticated algorithms like Merge Sort, Quick Sort, and Heap Sort all outperform Selection Sort with O(n log n) average time complexity.
