Merge Sort

A divide-and-conquer algorithm that splits the array into halves, recursively sorts each half, and then merges them back together.

Time Complexity: O(n log n) Space Complexity: O(n) Stable: Yes
Visualize Algorithm 
function mergeSort(arr) {
  if (arr.length <= 1) return arr;

  const mid = Math.floor(arr.length / 2);
  const left = arr.slice(0, mid);
  const right = arr.slice(mid);

  return merge(mergeSort(left), mergeSort(right));
}

function merge(left, right) {
  let result = [], leftIndex = 0, rightIndex = 0;

  while (leftIndex < left.length && rightIndex < right.length) {
    if (left[leftIndex] < right[rightIndex]) {
      result.push(left[leftIndex]);
      leftIndex++;
    } else {
      result.push(right[rightIndex]);
      rightIndex++;
    }
  }

  return result.concat(left.slice(leftIndex)).concat(right.slice(rightIndex));
}

How Merge Sort Works

Algorithm Description

Merge Sort is a divide-and-conquer algorithm. It divides the array into two halves, recursively sorts both halves, and then merges the two sorted halves together. This makes it one of the most efficient sorting algorithms for large datasets.

Key Characteristics

  • Divide and Conquer: Splits array into halves
  • Efficient for Large Datasets: Consistently performs well
  • Stable Sort: Preserves the order of equal elements
  • Not In-Place: Requires additional memory

Complexity Analysis

Time Complexity

  • Best Case: O(n log n) - Always performs at O(n log n)
  • Average Case: O(n log n) - Average performance across various input scenarios
  • Worst Case: O(n log n) - Always performs at O(n log n)

Space Complexity

O(n) - Merge Sort requires additional space for temporary arrays used in merging.

When to Use Merge Sort

  • When dealing with large datasets
  • When memory usage is not a major concern
  • When a stable sort is required

    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left = arr[:mid]
    right = arr[mid:]

    return merge(merge_sort(left), merge_sort(right))

def merge(left, right):
    result = []
    left_index, right_index = 0, 0

    while left_index < len(left) and right_index < len(right):
        if left[left_index] < right[right_index]:
            result.append(left[left_index])
            left_index += 1
        else:
            result.append(right[right_index])
            right_index += 1

    return result + left[left_index:] + right[right_index:]

import java.util.Arrays;

public class MergeSort {
    public static int[] mergeSort(int[] arr) {
        if (arr.length <= 1) return arr;

        int mid = arr.length / 2;
        int[] left = Arrays.copyOfRange(arr, 0, mid);
        int[] right = Arrays.copyOfRange(arr, mid, arr.length);

        return merge(mergeSort(left), mergeSort(right));
    }

    public static int[] merge(int[] left, int[] right) {
        int[] result = new int[left.length + right.length];
        int leftIndex = 0, rightIndex = 0, resultIndex = 0;

        while (leftIndex < left.length && rightIndex < right.length) {
            if (left[leftIndex] < right[rightIndex]) {
                result[resultIndex++] = left[leftIndex++];
            } else {
                result[resultIndex++] = right[rightIndex++];
            }
        }

        while (leftIndex < left.length) result[resultIndex++] = left[leftIndex++];
        while (rightIndex < right.length) result[resultIndex++] = right[rightIndex++];

        return result;
    }

    public static void main(String[] args) {
        int[] arr = {38, 27, 43, 3, 9, 82, 10};
        System.out.println("Sorted array: " + Arrays.toString(mergeSort(arr)));
    }
}

std::vector mergeSort(std::vector& arr) {
    if (arr.size() <= 1) return arr;

    int mid = arr.size() / 2;
    std::vector left(arr.begin(), arr.begin() + mid);
    std::vector right(arr.begin() + mid, arr.end());

    return merge(mergeSort(left), mergeSort(right));
}

std::vector merge(std::vector& left, std::vector& right) {
    std::vector result;
    int leftIndex = 0, rightIndex = 0;

    while (leftIndex < left.size() && rightIndex < right.size()) {
        if (left[leftIndex] < right[rightIndex]) {
            result.push_back(left[leftIndex]);
            leftIndex++;
        } else {
            result.push_back(right[rightIndex]);
            rightIndex++;
        }
    }

    result.insert(result.end(), left.begin() + leftIndex, left.end());
    result.insert(result.end(), right.begin() + rightIndex, right.end());

    return result;
}
