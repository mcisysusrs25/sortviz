Insertion Sort

A simple sorting algorithm that builds the final sorted array one item at a time by comparing each element with the already sorted part of the array.

Time Complexity: O(n²) Space Complexity: O(1) Stable: Yes
Visualize Algorithm 
function insertionSort(arr) {
  const n = arr.length;
  
  for (let i = 1; i < n; i++) {
    // Current element to insert
    let key = arr[i];
    let j = i - 1;
    
    // Move elements greater than key
    // to one position ahead
    while (j >= 0 && arr[j] > key) {
      arr[j + 1] = arr[j];
      j = j - 1;
    }
    
    arr[j + 1] = key;
  }
  
  return arr;
}

How Insertion Sort Works

Algorithm Description

Insertion Sort is a simple sorting algorithm that works similar to how you might sort playing cards in your hand. The array is virtually split into sorted and unsorted parts. Values from the unsorted part are picked and placed in the correct position in the sorted part.

The algorithm iterates through an array, consuming one element each repetition, and builds a sorted array one element at a time. It's much less efficient on large lists than more advanced algorithms like quicksort, heapsort, or merge sort, but it has several advantages.

Key Characteristics

  • Simple Implementation: Easy to understand and implement
  • Efficient for Small Data Sets: Performs well with small arrays
  • Adaptive: Efficient for data sets that are already substantially sorted
  • Stable Sort: Maintains the relative order of equal elements
  • In-Place: Only requires a constant amount of extra memory space
  • Online: Can sort a list as it receives it

Complexity Analysis

Time Complexity

  • Best Case: O(n) - When the array is already sorted
  • Average Case: O(n²) - Average performance requires n²/4 comparisons and swaps
  • Worst Case: O(n²) - When the array is sorted in reverse order

Space Complexity

O(1) - Only requires a constant amount of extra memory space, as it sorts the array in-place.

When to Use Insertion Sort

  • Small datasets where simplicity and low overhead matter
  • Nearly sorted datasets where it can perform in almost linear time
  • When memory usage is a concern
  • As part of more complex algorithms (like hybrid sorting algorithms)
  • When implementing online algorithms (sorting as data arrives)

Code Implementation

function insertionSort(arr) {
  const n = arr.length;
  
  for (let i = 1; i < n; i++) {
    // Store the current element to be inserted
    let key = arr[i];
    
    // Initialize j to the element right before the current one
    let j = i - 1;
    
    // Move elements greater than key to one position ahead
    while (j >= 0 && arr[j] > key) {
      arr[j + 1] = arr[j];
      j = j - 1;
    }
    
    // Place the key in its correct position
    arr[j + 1] = key;
  }
  
  return arr;
}

            int key = arr[i];
            int j = i - 1;
            
            // Move elements of arr[0..i-1], that are
            // greater than key, to one position ahead
            // of their current position
            while (j >= 0 && arr[j] > key) {
                arr[j + 1] = arr[j];
                j = j - 1;
            }
            arr[j + 1] = key;
        }
    }
    
    public static void main(String[] args) {

    }
}
